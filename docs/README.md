# Документация `sk_speech`

Документация разделена на практические руководства и справочник API. Если вы
ещё не работали с пакетом, начните с первого руководства.

## Быстрый старт

Установите опубликованный пакет из PyPI:

```bash
python -m pip install sk-speech
```

Получите временные ряды F0, интенсивности и озвученности:

```python
from sk_speech import PitchExtractor

track = PitchExtractor().from_file("speech.wav")
track.to_csv("pitch_features.csv")

print(track.f0_hz)
print(track.intensity_db)
```

Для Python используется имя импорта `sk_speech`, хотя имя дистрибутива в
PyPI — `sk-speech`. Полная последовательность действий приведена в
руководстве [«С чего начать»](getting-started.md).

- [Анализ аудио](audio-analysis.md) — F0, интенсивность, форманты, гласные, шум и комплексный профиль;
- [Преобразование аудио](audio-transformation.md) — фильтрация, изменение F0, формант, скорости и громкости;
- [Калибровка и временные ряды](calibration-and-timeseries.md) — нейтральный профиль, отклонения F0 и интенсивности, экспорт в CSV.
- [Дыхание и голосообразование](physiological-modeling.md) — экспериментальные модели дыхательного цикла, воздушного потока, голосовой щели и физиологических регуляторов.
- [Публикация на PyPI](publishing.md) — проверка дистрибутивов, Trusted Publishing и выпуск новой версии.
