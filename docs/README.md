# Документация `sk_speech`

Документация разделена на практические руководства и справочник API. Если вы
ещё не работали с пакетом, начните с первого руководства.

## Практические руководства

- [С чего начать](getting-started.md) — установка, загрузка записи, первый анализ и сохранение результата;
- [Анализ аудио](audio-analysis.md) — F0, интенсивность, форманты, гласные, шум и комплексный профиль;
- [Преобразование аудио](audio-transformation.md) — фильтрация, изменение F0, формант, скорости и громкости;
- [Калибровка и временные ряды](calibration-and-timeseries.md) — нейтральный профиль, отклонения F0 и интенсивности, экспорт в CSV.

## Справочник

[API пакета](API.md) — оглавление и общие соглашения. Каждый модуль описан в
отдельном файле в каталоге [`api/`](api/). Для каждой публичной функции указаны
сигнатура, назначение, параметры и возвращаемое значение.

## Готовые сценарии

Каталог [`examples/`](../examples/) содержит запускаемые сценарии анализа, фильтрации, калибровки,
визуализации и преобразования речи. Их назначение и зависимости собраны в [описании примеров](../examples/README.md).
