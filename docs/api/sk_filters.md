# Фильтры и ERB-преобразования

[← К оглавлению API](../API.md)

Модуль: `sk_speech.sk_filters`.

Временные и частотные фильтры, эффекты, LMS и коэффициенты гамматонного банка.

## Класс `LMSFilter`

Адаптивный фильтр на основе алгоритма наименьших средних квадратов с изменяемыми весами.

```python
LMSFilter(order, step_size)
```

#### `LMSFilter.update`

```python
update(input_signal, desired_signal)
```

Рассчитывает выход LMS-фильтра для текущего окна, ошибку относительно желаемого значения и обновляет веса градиентным шагом.

**Параметры:**

- `input_signal` — входное окно сэмплов фильтра.
- `desired_signal` — целевое значение, с которым сравнивается выход фильтра.

**Возвращает:** `tuple` со значениями: `output, self.error`.

## Функции

#### `hz_to_semitones`

```python
hz_to_semitones(hz, reference_hz=440.0)
```

Переводит частоту в герцах в интервал полутонов относительно опорной частоты по логарифмической шкале 12-TET.

**Параметры:**

- `hz` — частота, Гц.
- `reference_hz` — опорная частота, относительно которой считаются полутона, Гц.

**Возвращает:** результат выражения `12 * np.log2(hz / reference_hz)`.

#### `semitones_to_hz`

```python
semitones_to_hz(semitones, reference_hz=440.0)
```

Переводит интервал в полутонах обратно в частоту относительно заданной опорной частоты.

**Параметры:**

- `semitones` — музыкальный интервал, полутоны.
- `reference_hz` — опорная частота, относительно которой считаются полутона, Гц.

**Возвращает:** результат выражения `reference_hz * 2 ** (semitones / 12)`.

**Возвращает:** `numpy.ndarray` — новый аудиосигнал после описанного преобразования.

#### `apply_reverb`

```python
apply_reverb(y, sr, reverb_factor=0.5, delay_ms=50, attenuation=0.5)
```

Добавляет к каждому сэмплу задержанную копию сигнала. Задержка задаётся в миллисекундах, а уровень отражения — произведением `reverb_factor` и `attenuation`.

**Параметры:**

- `y` — одномерный аудиосигнал `numpy.ndarray`.
- `sr` — частота дискретизации, Гц.
- `reverb_factor` — доля задержанной копии в эффекте реверберации.
- `delay_ms` — задержка отражённой копии, мс.
- `attenuation` — коэффициент затухания задержанной копии.

**Возвращает:** `numpy.ndarray` — новый аудиосигнал после описанного преобразования.

#### `match_target_amplitude`

```python

```

Изменяет усиление объекта `pydub.AudioSegment`, чтобы его средний уровень стал равен `target_dBFS`.

**Параметры:**

- `sound` — объект аудиосигнала Praat или Pydub согласно функции.
- `target_dBFS` — целевой средний цифровой уровень, dBFS.

**Возвращает:** результат выражения `sound.apply_gain(change_in_dBFS)`.

#### `train_adaptive_filter`

```python

```

Обучает LMS-фильтр предсказывать следующий сэмпл нормализованной эталонной записи.

**Параметры:**

- `order` — порядок фильтра или число его коэффициентов.

#### `apply_adaptive_filter`

```python

```

Применяет обученный LMS-фильтр к входному файлу и записывает отфильтрованный сигнал в `output_file`.

**Параметры:**

- `input_file` — путь к входному аудиофайлу.
- `output_file` — путь к выходному аудиофайлу.
- `lms_filter` — обученный объект `LMSFilter`.
- `order` — порядок фильтра или число его коэффициентов.

**Возвращает:** `None`; результат отображается, записывается в файл или сохраняется во внутреннем состоянии.

#### `erb_point`

```python
erb_point(low_freq, high_freq, fraction)
```

Рассчитывает одну частоту между нижней и верхней границами по психоакустической шкале ERB Гласберга—Мура.

**Параметры:**

- `low_freq` — нижняя граница частотного диапазона, Гц.
- `high_freq` — верхняя граница частотного диапазона, Гц.
- `fraction` — положение точки между границами в координатах ERB.

**Возвращает:** результат выражения `erb_point`.

#### `erb_space`

```python
erb_space(low_freq=DEFAULT_LOW_FREQ, high_freq=DEFAULT_HIGH_FREQ, num=DEFAULT_FILTER_NUM)
```

Формирует массив частот, равномерно расположенных в координатах ERB между заданными границами.

**Параметры:**

- `low_freq` — нижняя граница частотного диапазона, Гц.
- `high_freq` — верхняя граница частотного диапазона, Гц.
- `num` — число создаваемых значений.

**Возвращает:** результат выражения `erb_point(low_freq, high_freq, np.arange(1, num + 1) / num)`.

#### `erb_filterbank`

```python
erb_filterbank(wave, coefs)
```

Пропускает сигнал через каждый канал ERB-банка и возвращает матрицу выходов размерности «канал × сэмпл».

**Параметры:**

- `wave` — одномерный входной аудиосигнал.
- `coefs` — коэффициенты каналов ERB-фильтра.

**Возвращает:** `numpy.ndarray` — рассчитанный сигнал или числовая последовательность.
