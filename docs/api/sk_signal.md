# Генерация сигналов

[← К оглавлению API](../API.md)

Модуль: `sk_speech.sk_signal`.

Гармонические компоненты, временные оси, сборка и сохранение синтетического сигнала.

## Функции

#### `calculate_harmonic_frequencies`

```python
calculate_harmonic_frequencies(Freq_range, Bw_range, N, t)
```

Рассчитывает изменяющиеся во времени частоты гармоник внутри заданного частотного диапазона.

**Параметры:**

- `Freq_range` — начальная и конечная частоты синтезируемой компоненты, Гц.
- `Bw_range` — начальная и конечная ширины полосы, Гц.
- `N` — номер гармоники или число компонент согласно функции.
- `t` — время или массив временных координат, с.

**Возвращает:** `numpy.ndarray` — рассчитанный сигнал или числовая последовательность.

#### `calculate_harmonic_amplitudes`

```python
calculate_harmonic_amplitudes(Freq_range, f_k, Amp_range, Bw_range, t)
```

Рассчитывает амплитуды гармоник с учётом целевого диапазона амплитуд и ширины полос.

**Параметры:**

- `Freq_range` — начальная и конечная частоты синтезируемой компоненты, Гц.
- `f_k` — мгновенная частота гармоники, Гц.
- `Amp_range` — начальная и конечная амплитуды синтезируемой компоненты.
- `Bw_range` — начальная и конечная ширины полосы, Гц.
- `t` — время или массив временных координат, с.

**Возвращает:** `numpy.ndarray` — рассчитанный сигнал или числовая последовательность.

#### `generate_time_axis`

```python
generate_time_axis(rate, duration)
```

Создаёт равномерную временную сетку требуемой длительности и частоты дискретизации.

**Параметры:**

- `rate` — частота дискретизации, Гц.
- `duration` — длительность, с.

**Возвращает:** результат выражения `np.linspace(0, duration, int(rate * duration), endpoint=False)`.

#### `generate_harmonic_signal`

```python
generate_harmonic_signal(f_k, A_k, t)
```

Генерирует массив синусоидальных компонентов по частотам и амплитудам на каждом временном шаге.

**Параметры:**

- `f_k` — мгновенная частота гармоники, Гц.
- `A_k` — мгновенная амплитуда гармоники.
- `t` — время или массив временных координат, с.

**Возвращает:** `numpy.ndarray` — рассчитанный сигнал или числовая последовательность.

#### `save_to_wav`

```python
save_to_wav(signal, rate, filename)
```

Нормализует и сохраняет массив аудиосэмплов в WAV-файл.

**Параметры:**

- `signal` — одномерный аудиосигнал `numpy.ndarray`.
- `rate` — частота дискретизации, Гц.
- `filename` — имя или путь к файлу.

**Возвращает:** `None`; результат отображается, записывается в файл или сохраняется во внутреннем состоянии.

#### `create_signal`

```python
create_signal(Freq_range, Amp_range, Bw_range, duration, rate=44100, num_harmonics=5)
```

Создаёт многокомпонентный гармонический сигнал по диапазонам частоты, амплитуды и полосы.

**Параметры:**

- `Freq_range` — начальная и конечная частоты синтезируемой компоненты, Гц.
- `Amp_range` — начальная и конечная амплитуды синтезируемой компоненты.
- `Bw_range` — начальная и конечная ширины полосы, Гц.
- `duration` — длительность, с.
- `rate` — частота дискретизации, Гц.
- `num_harmonics` — число синтезируемых гармоник.

**Возвращает:** `numpy.ndarray` — рассчитанный сигнал или числовая последовательность.

#### `combine_signals`

```python
combine_signals(signals)
```

Суммирует набор сигналов одинаковой длины в один массив.

**Параметры:**

- `signals` — последовательность одномерных сигналов одинаковой длины.

**Возвращает:** `numpy.ndarray` — рассчитанный сигнал или числовая последовательность.
