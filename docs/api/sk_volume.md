# Комплексный профиль и преобразование речи

[← К оглавлению API](../API.md)

Модуль: `sk_speech.sk_volume`.

Объединение акустических признаков, профили, векторы, пакетная обработка и комплексное изменение речи.

## Функции

#### `create_empty_value`

```python
create_empty_value(template_speech=False)
```

Создаёт пустую структуру одного акустического признака с полями частоты, энергии, интенсивности, амплитуды, полосы и динамики.

**Параметры:**

- `template_speech` — включить режим эталонного профиля речи.

**Возвращает:** `dict` со структурированными результатами расчёта.

#### `create_empty_formant`

```python
create_empty_formant()
```

Создаёт пустую структуру форманты с полями частоты, ширины, энергии, интенсивности, амплитуды и временной динамики.

**Возвращает:** `dict` со структурированными результатами расчёта.

#### `load_vectors_from_json`

```python
load_vectors_from_json(file_path)
```

Загружает данные из файла.

**Параметры:**

- `file_path` — путь к файлу.

**Возвращает:** результат выражения `speech`.

#### `trim_silence`

```python
trim_silence(y, sr, top_db=20, apply_noise_reduction=False)
```

Удаляет тишину в начале и в конце аудиофайла и при необходимости применяет шумоподавление.

**Параметры:**

- `y` — одномерный аудиосигнал `numpy.ndarray`.
- `sr` — частота дискретизации, Гц.
- `top_db` — порог тишины относительно максимального уровня, дБ.
- `apply_noise_reduction` — включить шумоподавление перед обрезкой.

**Возвращает:** результат выражения `y_trimmed`.

#### `detect_leading_silence`

```python
detect_leading_silence(sound, silence_threshold=-50.0, chunk_size=10)
```

Проходит объект `AudioSegment` короткими блоками и возвращает длительность начальной тишины до первого блока выше порога.

**Параметры:**

- `sound` — объект аудиосигнала Praat или Pydub согласно функции.
- `silence_threshold` — порог принятия решения.
- `chunk_size` — размер блока анализа, мс.

**Возвращает:** результат выражения `trim_ms`.

#### `trim_silence_pydub`

```python
trim_silence_pydub(sound)
```

Удаляет из `AudioSegment` начальную и конечную тишину, найденную `detect_leading_silence`.

**Параметры:**

- `sound` — объект аудиосигнала Praat или Pydub согласно функции.

**Возвращает:** результат выражения `trimmed_sound`.

#### `calculate_intensity_avg`

```python
calculate_intensity_avg(y, sr)
```

Строит объект Intensity Praat и возвращает среднюю интенсивность записи в децибелах.

**Параметры:**

- `y` — одномерный аудиосигнал `numpy.ndarray`.
- `sr` — частота дискретизации, Гц.

**Возвращает:** `float` — объединённая средняя интенсивность речи.

#### `calculate_intensity_max`

```python
calculate_intensity_max(y, sr)
```

Строит объект Intensity Praat и возвращает максимальную интенсивность записи в децибелах.

**Параметры:**

#### `transition`

```python
transition(V_norm, V_loud, alpha)
```

Линейно интерполирует между нормальным и громким значениями по коэффициенту `alpha`.

**Параметры:**

- `V_norm` — значение параметра для нормальной речи.
- `V_loud` — значение параметра для громкой речи.
- `alpha` — коэффициент перехода или формы фазы согласно методу.

**Возвращает:** `float` — интерполированное значение между нормальным и громким режимами речи.

#### `calculate_pitch_shift_semitones`

```python
calculate_pitch_shift_semitones(frequency_change)
```

Переводит относительное изменение частоты в сдвиг в полутонах по логарифмической шкале.

**Параметры:**

- `frequency_change` — частота или последовательность частот, Гц.

**Возвращает:** `float` — требуемый сдвиг F0 в полутонах.

#### `energy_speech`

```python
energy_speech(volume)
```

Преобразует относительную громкость в энергетический множитель, используемый в комплексном преобразовании речи.

**Параметры:**

- `volume` — уровень или коэффициент громкости.

**Возвращает:** `tuple` со значениями: `energy_pitch_factor, pitch_shift_semitones, formant_bandwidth_factors, formant_energy_factors, formant_shifts, formant_energy_vowel`.

#### `change_speech_volume`

```python
change_speech_volume(y, sr, volume, is_noise=False, is_shift=False)
```

Создаёт преобразованный аудиосигнал, изменяя суммарную воспринимаемую громкость речи.

**Параметры:**

- `y` — одномерный аудиосигнал `numpy.ndarray`.
- `sr` — частота дискретизации, Гц.
- `volume` — уровень или коэффициент громкости.
- `is_noise` — включить предварительное шумоподавление.
- `is_shift` — включить коррекцию постоянного смещения.

**Возвращает:** `numpy.ndarray` — новый аудиосигнал после описанного преобразования.

#### `change_volume`

```python
change_volume(y, sr, volume_from, volume_to, is_noise=False, is_shift=False)
```

Плавно меняет громкость от `volume_from` до `volume_to`, при необходимости включая шумоподавление и сдвиг нулевого уровня.

**Параметры:**

- `y` — одномерный аудиосигнал `numpy.ndarray`.
- `sr` — частота дискретизации, Гц.
- `volume_from` — множитель громкости в начале сигнала.
- `volume_to` — множитель громкости в конце сигнала.
- `is_noise` — включить предварительное шумоподавление.
- `is_shift` — включить коррекцию постоянного смещения.

**Возвращает:** результат выражения `y_filtered | y`.

- `min_false_duration` — коэффициент или доля преобразования.
- `pitch_margin` — данные или параметры основного тона F0.

**Возвращает:** результат выражения `trimmed_segments`.

#### `set_speed`

```python
set_speed(input_file, output_file, speed)
```

Меняет скорость воспроизведения файла через `pydub`, заменяя частоту кадров и возвращая её к исходной перед сохранением.

**Параметры:**

- `input_file` — путь к входному аудиофайлу.
- `output_file` — путь к выходному аудиофайлу.
- `speed` — множитель скорости воспроизведения.

**Возвращает:** `None`; результат отображается, записывается в файл или сохраняется во внутреннем состоянии.

#### `generate_signal`

```python
generate_signal(frequencies, bandwidths, intensities, times, delta_time, energy_correction=0, sr=44100)
```

Генерирует аудиосигнал на основе массивов частот, ширины канала и интенсивности.

**Параметры:**

- `frequencies` — частоты или последовательности частот.
- `bandwidths` — ширины частотных полос, Гц.
- `intensities` — значения интенсивности.
- `times` — временные координаты, с.
- `delta_time` — шаг времени, с.
- `energy_correction` — энергия или коэффициент энергии.
- `sr` — частота дискретизации, Гц.

**Возвращает:** `numpy.ndarray` — рассчитанный сигнал или числовая последовательность.

#### `mix_audio_signals`

```python
mix_audio_signals(audio_signals)
```

Смешивает несколько аудиосигналов разной длины, добавляя тишину там, где сигнал отсутствует, и возвращает один аудиосигнал с длиной, равной максимальной длине среди всех сигналов.

**Параметры:**

- `audio_signals` — последовательность массивов аудиосэмплов.

**Возвращает:** `numpy.ndarray` — рассчитанный сигнал или числовая последовательность.
