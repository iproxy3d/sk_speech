# Голосовая щель и воздушный поток

[← К оглавлению API](../API.md)

Модуль: `sk_speech.sk_vocal_cords`.

Физические оценки площади голосовой щели, сопротивления, потока, давления и SPL.

## Функции

#### `calculate_base_S0`

```python
calculate_base_S0(Base0, height, height_gender)
```

Масштабирует базовую площадь голосовой щели пропорционально росту относительно эталона для пола.

**Параметры:**

- `Base0` — базовая площадь голосовой щели для эталонного роста.
- `height` — рост, используемый физической моделью.
- `height_gender` — эталонный рост для выбранного пола.

**Возвращает:** `float` — базовая площадь голосовой щели с поправкой на рост.

#### `calculate_min_S_fast`

```python
calculate_min_S_fast(Base_min, height, height_gender, factor_fast)
```

Рассчитывает минимальную площадь щели для быстрой составляющей напряжения с учётом роста.

**Параметры:**

- `Base_min` — базовая минимальная площадь голосовой щели.
- `height` — рост, используемый физической моделью.
- `height_gender` — эталонный рост для выбранного пола.
- `factor_fast` — коэффициент или доля преобразования.

**Возвращает:** `float` — минимальная площадь голосовой щели для быстрой составляющей.

#### `calculate_min_S_slow`

```python
calculate_min_S_slow(Base_min, height, height_gender, factor_slow)
```

Рассчитывает минимальную площадь щели для медленной составляющей напряжения с учётом роста.

**Параметры:**

- `Base_min` — базовая минимальная площадь голосовой щели.
- `height` — рост, используемый физической моделью.
- `height_gender` — эталонный рост для выбранного пола.
- `factor_slow` — коэффициент или доля преобразования.

**Возвращает:** `float` — минимальная площадь голосовой щели для медленной составляющей.

#### `get_S`

```python
get_S(gender=None, height=None)
```

Возвращает набор базовых и минимальных площадей голосовой щели, подобранных по полу и росту.

**Параметры:**

- `gender` — пол или голосовая категория, используемая моделью.
- `height` — рост, используемый физической моделью.

**Возвращает:** `tuple` со значениями: `S0, S_min_fast, S_min_slow`.

#### `fS_t1`

```python
fS_t1(t, T0, alpha)
```

Вычисляет форму фазы открытия голосовой щели как степень синуса на периоде F0.

**Параметры:**

- `t` — время или массив временных координат, с.
- `T0` — период одного цикла F0, с.
- `alpha` — коэффициент перехода или формы фазы согласно методу.

**Возвращает:** результат выражения `np.sin(1.5 * np.pi * t / T0) ** alpha`.

#### `fS_t2`

```python
fS_t2(t, T0, beta)
```

Вычисляет форму фазы закрытия голосовой щели как степень косинуса на периоде F0.

**Параметры:**

- `t` — время или массив временных координат, с.
- `T0` — период одного цикла F0, с.
- `beta` — коэффициент формы, чувствительности или затухания согласно методу.

**Возвращает:** результат выражения `np.cos(0.5 * np.pi * (3.0 * t - T0) / T0) ** beta`.

#### `calculate_dynamic_area`

```python
calculate_dynamic_area(S_max, T0, alpha, beta)
```

Строит временной ряд площади голосовой щели на одном периоде открытия и закрытия.

**Параметры:**

- `S_max` — максимальная площадь открытия голосовой щели.
- `T0` — период одного цикла F0, с.
- `alpha` — коэффициент перехода или формы фазы согласно методу.
- `beta` — коэффициент формы, чувствительности или затухания согласно методу.

**Возвращает:** `float` — средняя динамическая площадь голосовой щели.

#### `calculate_S`

```python
calculate_S(T0, S0, Stress_fast, Stress_slow, alpha, beta, w, S_min_fast, S_min_slow)
```

Рассчитывает динамику площади голосовой щели по периоду F0, быстрому и медленному напряжению и параметрам фаз.

**Параметры:**

- `T0` — период одного цикла F0, с.
- `S0` — Базовая площадь голосовой щели при спокойной речи (м²).
- `Stress_fast` — Значение стресса для быстрой реакции (от 0 до 1).
- `Stress_slow` — Значение стресса для медленной реакции (от 0 до 1).
- `alpha` — Коэффициент для экспоненциальной функции для медленного стресса.
- `beta` — Пороговое значение стресса для медленного стресса.
- `w` — Весовой коэффициент для перехода между быстрым и медленным стрессом.
- `S_min_fast` — Минимальная площадь голосовой щели при быстром стрессе (м²).
- `S_min_slow` — Минимальная площадь голосовой щели при медленном стрессе (м²).

**Возвращает:** `float` — текущая площадь открытия голосовой щели.

#### `calculate_diameter`

```python
calculate_diameter(height, sex)
```

Оценивает диаметр дыхательных путей по росту и полу.

**Параметры:**

- `height` — Рост человека (см).
- `sex` — Пол человека ('male' или 'female').

**Возвращает:** `float` — оценочный диаметр голосовой щели с поправкой на рост.

#### `calculate_length`

```python
calculate_length(height)
```

Оценивает длину дыхательных путей как долю роста.

**Параметры:**

- `height` — Рост человека (см).

**Возвращает:** `float` — оценочная длина голосовых складок с поправкой на рост.

#### `hagen_poiseuille_resistance`

```python
hagen_poiseuille_resistance(length, radius, viscosity=1.8e-05)
```

Рассчитывает ламинарное сопротивление цилиндрического дыхательного канала по закону Гагена—Пуазейля.

**Параметры:**

- `length` — Длина трубы (м).
- `radius` — Радиус трубы (м).
- `viscosity` — Вязкость воздуха (Па·с).

**Возвращает:** результат выражения `resistance`.

#### `darcy_weisbach_resistance`

```python
darcy_weisbach_resistance(friction_factor, length, diameter)
```

Рассчитывает сопротивление потоку по формуле Дарси—Вейсбаха из коэффициента трения, длины и диаметра.

**Параметры:**

- `friction_factor` — Коэффициент трения.
- `length` — Длина трубы (м).
- `diameter` — Диаметр трубы (м).

**Возвращает:** результат выражения `resistance`.

#### `reynolds_number`

```python
reynolds_number(flow_rate, diameter, viscosity=1.81e-05, rho=1.225)
```

Рассчитывает число Рейнольдса для воздушного потока по расходу, диаметру, вязкости и плотности.

**Параметры:**

- `flow_rate` — Скорость потока (м³/с).
- `diameter` — Диаметр трубы (м).
- `viscosity` — Вязкость воздуха (Па·с) ~ 1.81e-5.
- `rho` — плотность воздуха или среды, кг/м³.

**Возвращает:** результат выражения `re_number`.

#### `calculate_flow`

```python
calculate_flow(V, T, S)
```

Рассчитывает объёмный расход воздуха по объёму, времени и площади прохода.

**Параметры:**

- `V` — объём воздуха.
- `T` — толщина мембраны, температура или время согласно модели.
- `S` — площадь, масштаб или параметр чувствительности согласно модели.

**Возвращает:** `float` — скорость воздушного потока через голосовую щель.

#### `calculate_subglottic_pressure`

```python
calculate_subglottic_pressure(flow_rate, rho=1.225)
```

Оценивает субглоттальное давление по динамическому давлению воздушного потока.

**Параметры:**

- `flow_rate` — Скорость воздушного потока (м/с).
- `rho` — Плотность воздуха (кг/м³).

**Возвращает:** `float` — подскладочное давление.

#### `calculate_spl`

```python
calculate_spl(height, sex, F0, volume_air, time_speech, Stress_fast, Stress_slow)
```

Оценивает уровень звукового давления по геометрии дыхательных путей, F0, объёму воздуха, длительности речи и напряжению.

**Параметры:**

- `height` — рост, используемый физической моделью.
- `sex` — пол, используемый для выбора физиологических коэффициентов.
- `F0` — частота основного тона, Гц.
- `volume_air` — объём воздуха, расходуемого на речь.
- `time_speech` — временной параметр, с, если функция не указывает другую единицу.
- `Stress_fast` — быстрая составляющая напряжения голосовых складок.
- `Stress_slow` — медленная составляющая напряжения голосовых складок.

**Возвращает:** `float` — расчётный уровень звукового давления, дБ SPL.
