# Примеры

Для использования функций пакета в собственном коде установите опубликованный
выпуск с зависимостями для расширенных примеров:

```bash
python -m pip install "sk-speech[examples]"
```

Сами сценарии хранятся в репозитории. Чтобы запускать и изменять их локально:

```bash
git clone https://github.com/iproxy3d/sk_speech.git
cd sk_speech
python -m pip install -e ".[examples]"
```

Большинство сценариев работают с WAV-файлами. Перед запуском укажите путь к
собственной записи в аргументах командной строки или в переменных `input_file`,
`file_path`, `directory` внутри конкретного сценария.

## Наглядные результаты

Каталог [`materials/`](../materials/) содержит видео результатов и схемы,
которые объясняют происходящие преобразования. Полное описание находится в
[галерее экспериментальных материалов](../materials/README.md).

| Направление | Что можно посмотреть | Связанный код |
|---|---|---|
| Интонация и F0 | Постоянная, растущая и затухающая амплитуда колебаний; один контур на разных репликах | [`test_volume.py`](test_volume.py), [API `sk_pitch`](../docs/api/sk_pitch.md) |
| Громкость и профиль | Простое усиление и интерактивное преобразование относительно эталона | [`test_volume.py`](test_volume.py), [`test_vol_em.py`](test_vol_em.py) |
| Длительность звуков | Исходная, ускоренная, замедленная и протяжённая речь | [`test_vowels.py`](test_vowels.py), [API `sk_vowels`](../docs/api/sk_vowels.md) |
| Гамматонная фильтрация | Исходный и обработанный сигнал на осциллограмме и спектрограмме | [модуль `sk_gammatone`](../src/sk_speech/sk_gammatone.py) |

## Готовые сценарии командной строки

| Файл | Назначение | Запуск |
|---|---|---|
| `pitch_features.py` | Последовательность F0, intensity и voiced mask | `python examples/pitch_features.py speech.wav --output features.csv` |
| `calibrate_pitch.py` | Нейтральный профиль и нормализованная последовательность | `python examples/calibrate_pitch.py neutral.wav --audio current.wav` |

## Анализ и преобразование речи

| Файл | Что показывает |
|---|---|
| `test_pitch.py` | Извлечение, наклон, выравнивание и преобразование F0 |
| `test_formants.py` | Частоты, полосы, энергия, интенсивность и преобразования F1–F5 |
| `test_volume.py` | Полный профиль речи и изменение pitch/формант/громкости |
| `test_vowels.py` | Поиск гласных и изменение их формант и длительности |
| `test_detection.py` | Тихая и громкая речь, шёпот и крик |
| `test_noise.py` | RMS, spectral flatness, PSD и подавление шума |
| `test_filters.py` | Нормализация, полосовая фильтрация и сглаживание |
| `test_vocal_tract.py` | Связь длины голосового тракта с F1–F5 |
| `dolphine.py` | Сегментация речи с изменением скорости, F0 и формант |
| `intervals.py` | Динамика F0/формант и общие временные интервалы признаков |

## Профили и наборы записей

| Файл | Что показывает |
|---|---|
| `test_em.py` | Извлечение набора акустических параметров из папки записей |
| `test_em_period.py` | Сравнение периодических параметров с нейтральным профилем |
| `step1.py` | Подготовка структуры WAV-файлов по идентификаторам говорящих |
| `step2.py` | Пакетная обработка подготовленных записей по говорящим |
| `test_pause.py` | Выделение пауз и сравнение методов их кластеризации |

## Синтез и интерактивные демонстрации

| Файл | Что показывает |
|---|---|
| `frac.py` | Генерация многомасштабного фрактального звукового сигнала |
| `test_vol.py` | Физическая модель голосовой щели, давления и воздушного потока |
| `test_vol_em.py` | Интерактивное управление преобразованием речи через GUI |
| `test_module.py` | Совместная модель дыхания, голоса и физиологических параметров |

Сценарии с графическим интерфейсом или воспроизведением звука требуют
доступного аудиоустройства и оконной среды. `test_pause.py` использует
дополнительную зависимость `hdbscan`, а `test_module.py` — `pyworld`; обе
устанавливаются через extra `examples`.
