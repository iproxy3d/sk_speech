# Авторские заметки из истории диалогов

В [исходной хронологии][history] автор записывал ход и результаты работы с реальными аудиозаписями, измерений в Praat и других программных тестов. Результаты приводятся в объёме, зафиксированном автором. Графики, WAV и настройки служат материалами для повторения замеров. Ссылки на строки закреплены за ревизией `6347655`. Дата указана там, где её можно отнести к сообщению. Для комментариев и вставок с неясным авторством это отмечено в тексте.

## Результаты выполненных анализов

| Анализ | Что получил автор |
|---|---|
| [Дыхательная пауза](breathing.md#breath-pause-estimate-example) | В одном фрагменте измерено 0,47 с. Оценка по формуле составила 0,42 с. |
| [Кластеризация пауз](breathing.md#pause-clustering-comparison) | На рассмотренных записях автоматический выбор числа кластеров раздробил короткие паузы. В тесте с ASR возникли ошибки определения границ слов. |
| [Изменение голосового профиля](voice.md#voice-profile-volume-trial) | В тестах сдвиг и масштабирование частот дали близкий по оценке автора эффект. Для дальнейшей работы он выбрал масштабирование с автоматическим сдвигом и регулировкой амплитуды. |
| [Профессиональная озвучка](voice.md#formant-pattern-observations-tables) | В таблицах по проанализированным репликам автор выделил выраженные изменения F3. |
| [Спектральные градиенты](gradients.md#cross-species-acoustic-gradients-shape) | На фазовых графиках разных записей автор наблюдал визуально сходную крестообразную форму. |
| [Центры кластеров и гамматон](gradients.md#gammatone-cluster-comparison-configurations) | Для настроек с 7 и 5 кластерами автор получил корреляции около 0,963 и 0,962. |
| [Praat на записи дельфина](gradients.md#dolphin-pitch-tracking-trial) | Исходный запуск трекера не выделил ожидаемую частотную дорожку. В хронологии зафиксирована последующая проба с замедлением аудио. |

## Как читать статусы

Поле `statement_type` описывает происхождение или роль утверждения.

| Значение | Роль |
|---|---|
| `observation` | Результат измерения, теста или просмотра данных, зафиксированный автором. |
| `calculation` | Численный расчёт или подстановка. |
| `procedure` | Описанный способ обработки или опыт. |
| `heuristic` | Рабочее правило или черновая модель. |
| `hypothesis` | Предположение, требующее проверки. |
| `analogy` | Сопоставление механизмов или представлений. |
| `external_summary` | Изложение содержания внешнего материала. |
| `dialogue_summary` | Изложение ответа собеседника или LLM. |
| `research_question` | Открытый исследовательский вопрос. |

Поле `evidence_status` указывает, на чём основано утверждение. Для авторского эксперимента основание — описание проведённой работы и полученных результатов в хронологии.

| Значение | Основание |
|---|---|
| `arithmetic_checked` | Повторена арифметика на значениях из TXT. |
| `source_checked` | Изложение сверено с указанным источником. |
| `partially_checked` | Подтверждена часть утверждения или его контекст. |
| `code_partial` | Автор описал выполненный анализ, часть процедуры прослеживается в коде указанной ревизии. |
| `experiment_documented` | Автор зафиксировал выполненный анализ аудио, тест или полученное наблюдение. |
| `missing_material` | Вложение содержит существенную часть описания, например формулу или коэффициенты черновой модели. |
| `proposal` | Параметры или правило предложены в хронологии. |
| `unverified` | Гипотеза, интерпретация или аналогия, для которой в заметке указан способ дальнейшей проверки. |
| `open` | Ответ или критерий ещё предстоит определить. |

В TSV поля `source_start` и `source_end` указывают на включительный диапазон строк оригинала. Поле `note` ведёт к утверждению, `related_sources` содержит ссылки на его основание или ближайший технический аналог. Для внешних источников объём проверки доступен в карточках каталога.
