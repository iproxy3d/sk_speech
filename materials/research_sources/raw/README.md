# Исходные исследовательские материалы

Здесь хранятся **четыре исходных файла** без редакторской переработки. Они расположены правильно; переносить их в `docs/` или программный код `src/` не нужно.

- [`два типа речи.docx`](<два типа речи.docx>) — 18 страниц о двух предполагаемых режимах речи, эмоциях, дыхании, темпе, ритме и интонации.
- [`История - весь список ссылок и описаний.txt`](<История - весь список ссылок и описаний.txt>) — хронологическая подборка ссылок на публикации, выдержек из работ, наблюдений и авторских рассуждений по физиологии речи, эмоциям и звуку.
- [`Форма1.docx`](Форма1.docx) — 38 страниц авторских гипотез о происхождении языка, энергозатратах артикуляции, влиянии среды и взаимодействии носителей разных звуковых систем.
- [`Шестислойная модель.docx`](<Шестислойная модель.docx>) — 48 страниц (редакция 3, 08.05.2025) об авторской инженерной интерпретации шестислойного неокортекса, обратных связях и обработке признаков.

**Проверка:** все четыре файла сверены с оригиналами по Git blob SHA-1 и размеру, включая Windows-переносы строк (CRLF) в TXT. В [`../manifest.json`](../manifest.json) также указаны SHA-256 оригиналов.

Краткие аннотации и назначение архива: [`../README.md`](../README.md). Текстовые извлечения, когда они подготовлены, лежат отдельно в [`../snapshots/`](../snapshots/).

Рабочие гипотезы не следует представлять как подтверждённые исследования без независимой проверки.
