# Неизменённые исходники

Здесь должны лежать три оригинальных файла (имена сохраняются):

- `два типа речи.docx`
- `История - весь список ссылок и описаний.txt`
- `Теория_возникновения_языков_и_речи.docx`

Они пока не загружены в GitHub. Из-за ограничений передачи двоичных вложений через коннектор в репозитории размещены только полные доступные текстовые снимки (см. `../snapshots/`).

Используйте `../import_originals.sh` с директорией исходных файлов. Контрольные суммы опубликованы в `../manifest.json`; не изменяйте оригиналы при подготовке будущего корпуса.
