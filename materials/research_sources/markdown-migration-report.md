## Результаты исторической конвертации

До удаления оригиналов установлена парность якорей между HTML и Markdown: 30/30, 694/694 и 457/457. Исходные изображения были сверены с вложениями Word, все 68 перенесены без редактирования. Проверенные SHA-256, Git blob SHA-1, размер и предыдущий путь каждого DOCX оставлены в [манифесте](manifest.json) **как историческое происхождение**, а Git SHA-1 каждого изображения дополнительно записан для повторной проверки без DOCX.

Файлы DOCX и HTML удалены **только из текущей ветки**, а не из истории Git. До удаления их содержала ревизия `c2980b7bb116e1a3bd048bac64b8e39c33417b8d`. Восстановление возможно по этой ревизии.

## Оффлайн-проверка без Actions

[Валидатор Markdown](author-documents/verify_markdown.py) из полного локального checkout:

```bash
python materials/research_sources/author-documents/verify_markdown.py
```

Он проверяет наличие и непрерывность якорей, размеры корпусов, местные Markdown-ссылки, медиа и Git blob SHA-1 изображений, а также отсутствие ссылок на удалённые DOCX и HTML. Проверка по дереву репозитория не заменяет локальный запуск и визуальный просмотр на GitHub. Ранние акты [4.14](author-documents/stage-4.14-acceptance.md) и [4.8](author-documents/six-layer-model/transfer-4.8.md) являются **историческими протоколами** и отражают проверки, выполненные до удаления DOCX/HTML.

Это изменение формата не устраняет научные неопределённости, записанные в редакторских разборах.
