## 2. Проверка путей и офлайн-навигации

**Метод уже выполненной проверки:** все три HTML-файла и три снимка получены из этой ветки GitHub. Их ссылки разобраны **без сетевого обращения при разрешении каждой ссылки** и проверены по дереву объектов GitHub той же ревизии как по локальной карте файлов. Для внутренних `#anchor` проверены уникальность `id` и существование каждой цели. Для снимков сверены последовательные B-блоки/страницы и наличие соответствующего якоря в HTML. Эта проверка обнаруживает отсутствующие относительные файлы и якоря, но **не заменяет открытие страниц автономным браузером**.

Проверка `<link rel=stylesheet>` ссылается на существующий `author-documents/document.css`; каталоги `media/` содержат необходимые оригинальные файлы. В HTML нет дублированных идентификаторов. Поисковые снимки: «Два типа речи» ссылается на все 18 якорей `page-N`; «Происхождение речи и языка» охватывает 694 уникальных B-блока; «Шестислойная модель» содержит 381 последовательный B-блок, все они представлены в соответствующих HTML.

**Не выполнено в текущей среде:** запуск полноценного браузера по файловому пути `file://` на физически скачанной копии всех трёх страниц и сравнение снимков экрана с Word. У этого сеанса нет доступной локальной копии всего Git-дерева и браузера, работающего с ней; GitHub-инструменты проверяют структуру по файлам ветки. Для точной автономной повторной проверки без Actions добавлен [`verify_markdown.py`](verify_markdown.py), запускаемый из полного checkout командой `python materials/research_sources/author-documents/verify_markdown.py`. **Скрипт не выдаётся за уже запущенный на полном checkout.** Он сверит реальное разрешение файлов, все SHA-256/Git blob SHA-1 оригиналов, содержимое ZIP-медиа с локальными картинками, B-якоря и поисковые снимки. Визуальную сверку рендера всё равно следует выполнить отдельно в браузере.

## 5. Что завершено и что открыто

**Завершены**: публикация трёх HTML-страниц, трёх поисковых снимков, трёх редакторских разборов; проверка полного покрытия блоков/страниц, путей и внутренних HTML-якорей; регистрация оригиналов и формул; актуализация ссылок README и `manifest.json`, воспроизводимый автономный валидатор. Никакие GitHub Actions не запускались; для коммитов используется `[skip ci]`.

**Остаются ограничения приёмки**: автономное визуальное открытие полного скачанного дерева в реальном браузере не было доступно в этом запуске; без него **нельзя утверждать, что выполнена визуальная офлайн-приёмка**. Для ряда изображений остаются вопросы внешних лицензий, для шестислойной архитектуры — неразрешённые математические неоднозначности и исходные аудио, для которых невозможно полное независимое воспроизведение. Нельзя заменять отсутствие этих ресурсов выдуманными идентификаторами или экспериментальными метриками.

**Решение по статусу:** содержательная индексация и структурная проверка 4.14 выполнены; критерий реального офлайн-открытия в браузере отмечен отдельно как **непроверенный**. Раздел остаётся доступным для целевой дополнительной визуальной проверки, не блокируя чтение и навигацию по опубликованным материалам.
