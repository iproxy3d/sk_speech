### Техническое исправление локального запуска 4.7 (2026-11-16)

На Windows при запуске `extract_six_layer.py` обнаружен `SyntaxError: Non-UTF-8 code ... line 156` в локальной копии скрипта. Исходный файл в GitHub читается как UTF-8; для исключения повторного повреждения при локальном перекодировании исходный `.py` переведён в ASCII-only (русские строки представлены Python Unicode-escape, выходной текст остаётся русским). Перед запуском обновить ветку. На момент исправления статус 4.7 оставался частичным; после локального запуска и публикации результатов этап завершён (см. запись о приёмке ниже). GitHub Actions вручную не запускались.

### Завершение 4.13 — записи и графики градиентов (2026-11-16)

По [исходной заметке](../author-notes/gradients.md#cross-species-acoustic-gradients) и [хронологии](six-layer-model/gradient-records-4.13.md#1-проверенные-источники-и-хронология) восстановлен документированный автором анализ реальных аудиозаписей разных видов (строки 4095–4100), рассчитанных частотных градиентов и визуально похожих крестообразных распределений. **Это результаты уже проведённого автором исследования**, а не гипотетические планы эксперимента. В [акте 4.13](six-layer-model/gradient-records-4.13.md) подробно проверены оригинальные четыре PNG раздела S13 (40–43): на PNG40 приведены Shapiro–Wilk W=0.47, p=5.3e-172 и KS D=0.27, p=0.0; PNG41–43 содержат графы пауз/внимания и не дают самостоятельно измеренного 10%-порога. Связь PNG40 с конкретным запуском DBSCAN 05.11.2024 по одному сходству осей не утверждалась. Проверены также отдельные исторические наблюдения градиентов, гамматона и дельфина без объединения разных экспериментов.

В коде `src/sk_speech/sk_vowels.py` найден `calculate_peak_slopes()`: **вычисляется угол atan(Δf/(10·Δt)) в градусах**, а в историческом описании `Δf/Δt` имеет единицы Гц/с. Совпадение используемой ревизии кода с историческим запуском не установлено. Полный список запрашиваемых материалов: [раздел 5 акта](six-layer-model/gradient-records-4.13.md).
